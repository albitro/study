# SOP-004: 모터 전류 이상 대응 절차

**문서번호**: SOP-004
**개정**: Rev.1
**적용 설비**: APU 시리즈

## 1. 정상 전류 범위
- 무부하 운전: 1.0 ~ 2.0 A
- 정상 부하 평균: 4.5 ~ 5.5 A
- 최대 허용 피크: 7.0 A (10초 이내)

## 2. 이상 패턴별 원인

### 2.1 평균 전류 상승 (5.5 A → 6.5 A 이상)
- **가능 원인**:
  - 흡기 필터 막힘 (가장 빈번, 60% 이상)
  - 누설로 인한 부하 증가 (SOP-002 참조)
  - 베어링 마모 진행
- **확인 순서**: 필터 → 누설 → 진동/온도

### 2.2 피크 전류 급상승 (7.0 A 초과)
- **가능 원인**:
  - 압축기 로크업 / 베어링 손상 임박
  - 전기 결상 (3상 중 1상 이상)
  - 토출 밸브 고착
- **즉시 조치**: 비상 정지, 전기실 결상 확인

### 2.3 전류 진동/맥동
- **가능 원인**:
  - 압력 스위치 채터링
  - 부하 변동 (수요 패턴 변화)
- **확인**: Pressure_switch 신호 안정성

## 3. 흡기 필터 점검 (가장 흔한 케이스)
1. 압축기 정지
2. 필터 하우징 분리, 필터 엘리먼트 확인
3. 압력차 5 mbar 초과 시 교체 권장
4. 신품 교체 후 재기동, 전류 정상 복귀 확인

## 4. 베어링 점검 (5,000 시간 이상 운전 시)
- 진동 측정 (RMS 4.5 mm/s 초과 시 교체 검토)
- 청취 검사 (이상 소음)
- 윤활 상태 확인

## 5. 보고
- 전류 이상이 24시간 이내 재발 시 정밀 진단 의뢰
- 베어링 교체는 별도 작업지시서로 분리
