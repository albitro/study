# SOP-002: 공기 누설(Air Leak) 대응 절차

**문서번호**: SOP-002
**개정**: Rev.4
**적용 설비**: APU 시리즈

## 1. Air Leak 판정 기준
다음 중 2개 이상 충족 시 Air Leak 의심:
- TP2 압력이 7.0 bar 미만으로 회복되지 않음
- 압축기 무부하 시간 평소 대비 50% 이상 감소
- Motor_current 평균이 정상 대비 +30% 이상 상승
- 1시간 내 압축기 기동 횟수 평소의 2배 이상

## 2. 1차 점검 (5분 이내 수행)
1. 안전 거리에서 청각/시각으로 누설 위치 1차 확인
2. 토출 밸브 주변 비누 거품 테스트
3. Reservoirs 라인 플랜지 / 가스켓 육안 점검
4. 누설 위치 식별되면 단계 4로, 미식별 시 단계 3으로

## 3. 2차 점검 (정밀 진단)
1. 압축기 정지 후 잔압 0 bar 도달 대기 (안전상 필수)
2. 초음파 누설 탐지기로 라인 전체 스캔
3. O-ring / 가스켓 / 솔레노이드 밸브 분해 점검
4. 토출 밸브(DV) 솔레노이드 동작 시험

## 4. 조치
| 누설 위치 | 표준 조치 | 평균 소요 |
|----------|----------|----------|
| 토출 밸브 O-ring | O-ring 교체, 시트 청소 | 90분 |
| Reservoirs 라인 가스켓 | 가스켓 교체, 토크 재조정 | 120분 |
| DV 솔레노이드 불량 | 솔레노이드 교체 | 60분 |
| 흡기 필터 막힘 | 필터 교체 | 30분 |

## 5. 조치 후 검증
1. 압축기 기동 후 무부하 압력 상승 시간 측정 (정상: 8 bar 도달 < 90초)
2. 30분 무부하 운전, TP2 변동폭 ±0.2 bar 이내 확인
3. CMMS에 사례 등록 (case_id 자동 발급)

## 6. 안전 주의사항
- 8 bar 이상 잔압이 있는 상태에서 분해 금지
- 토출 라인 작업 시 LOTO (Lockout/Tagout) 필수
- 작업자 보호구: 보안경, 청력보호구
