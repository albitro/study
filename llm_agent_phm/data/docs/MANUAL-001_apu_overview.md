# MANUAL-001: APU 압축기 시스템 개요

**문서번호**: MANUAL-001
**적용 설비**: APU-01, APU-02, APU-03

## 1. 시스템 구성
APU(Air Production Unit)는 메트로 차량에 압축 공기를 공급하는 단위 장치이다.
- 모터 + 압축기 본체 + 토출 밸브(DV) + 저장조(Reservoirs) + 쿨러 + 제어부

## 2. 센서 구성

### 2.1 아날로그 센서 (7종)
| 센서 | 단위 | 정상 범위 | 설명 |
|------|------|----------|------|
| TP2 | bar | 7.0 ~ 9.5 | 압축기 토출부 압력 |
| TP3 | bar | 8.0 ~ 9.5 | 패널부 압력 (소비 후 잔압) |
| H1 | bar | 0 ~ 10 | 토출 밸브 개방 시 압력 |
| DV_pressure | bar | 0 ~ 9.5 | 토출 밸브 내부 압력 |
| Reservoirs | bar | 7.5 ~ 9.5 | 저장조 압력 (하류) |
| Oil_temperature | °C | 60 ~ 75 | 오일 온도 |
| Motor_current | A | 4.5 ~ 5.5 | 모터 전류 (정상 부하) |

### 2.2 디지털 센서 (8종)
- COMP: 압축기 ON/OFF
- DV_eletric: 토출 밸브 전기 신호
- Towers: 듀얼 타워 운전 상태
- MPG: 보호 신호
- LPS: 저압 스위치
- Pressure_switch: 압력 임계 스위치
- Oil_level: 오일 레벨 (HIGH=정상)
- Caudal_impulses: 유량 펄스

## 3. 운전 모드
- **정상 모드**: TP2 7.0 ~ 9.5 bar 자동 유지, COMP ON/OFF 반복
- **무부하 모드**: 압력 도달 시 압축기 OFF, 잔압 사용
- **부하 모드**: 임계 압력 이하에서 COMP ON, Motor_current 4.5 ~ 5.5 A

## 4. 일반 고장 유형 (빈도 순)
1. **Air Leak (공기 누설)** — 약 60%
   - 토출 밸브 O-ring, 가스켓, 라인 피팅
   - 대응: SOP-002
2. **Cooling Issue (냉각 이상)** — 약 15%
   - 쿨러 핀 오염, 환기 불량
   - 대응: SOP-003
3. **Oil Leak (오일 누설)** — 약 10%
   - 드레인 플러그, 가스켓
   - 대응: SOP-003
4. **Motor Overload (전류 과다)** — 약 10%
   - 흡기 필터, 베어링
   - 대응: SOP-004
5. **Sensor Drift (센서 오류)** — 약 5%
   - 정기 교체로 예방

## 5. 예방 정비 주기
- 일일: 압력/온도/전류 육안 점검 (SOP-001)
- 주간: 환기구 청소
- 월간: 흡기 필터 점검, O-ring 외관
- 분기: 오일 샘플 분석
- 연간: 전체 분해 정비, 센서 교정
