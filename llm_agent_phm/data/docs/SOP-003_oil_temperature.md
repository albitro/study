# SOP-003: 오일 온도/누설 이상 대응 절차

**문서번호**: SOP-003
**개정**: Rev.2
**적용 설비**: APU 시리즈

## 1. 판정 기준
### 1.1 오일 온도 이상
- 75°C 초과: 주의
- 85°C 초과: 경고 (부하 즉시 감소)
- 95°C 초과: 비상 정지

### 1.2 오일 누설 의심
- Oil_level 디지털 신호 LOW 알람
- 크랭크케이스 외부 오일 흔적
- 오일 보충 주기가 평소의 1/2 이하로 단축

## 2. 오일 온도 상승 원인별 대응
| 원인 | 점검 방법 | 조치 |
|------|----------|------|
| 쿨러 핀 오염 | 핀 표면 분진 육안 확인 | 압축공기로 청소 (6 bar) |
| 오일 점도 저하 | 샘플 채취 후 점도계 측정 | 오일 교환 (ISO VG 46 권장) |
| 환기구 막힘 | 외기 흐름 종이로 확인 | 환기구 청소, 필터 교체 |
| 부하 과다 | Motor_current 추세 확인 | SOP-002 진입 (누설 점검) |

## 3. 오일 누설 대응
1. 즉시 운전 정지, 잔압 해소
2. 외부 오일 흔적 위치 사진 촬영
3. 주요 점검 부위:
   - 크랭크케이스 드레인 플러그 (가장 흔함)
   - 오일 필터 가스켓
   - 오일 라인 피팅 연결부
4. 누설 부위 실링 후 오일 보충 (사양: ISO VG 46, 5L)
5. 1시간 시운전 후 누설 재발 여부 확인

## 4. 오일 교환 권장 주기
- 정상 운전: 4,000 시간 또는 12개월 중 빠른 시점
- 고온 환경(평균 80°C↑): 2,000 시간으로 단축
- 누설 사고 후: 즉시 전량 교환

## 5. 폐오일 처리
- 지정 폐기물 업체 위탁
- 작업 일지에 폐기량(L) 기록
