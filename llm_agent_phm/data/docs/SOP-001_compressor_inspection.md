# SOP-001: APU 압축기 일상 점검 절차

**문서번호**: SOP-001
**개정**: Rev.3
**적용 설비**: APU 시리즈 (APU-01, APU-02, APU-03)

## 1. 점검 주기
- 일상 점검: 매 근무조 시작 시 (1일 3회)
- 주간 점검: 매주 월요일 오전
- 월간 점검: 매월 1일

## 2. 일상 점검 항목

### 2.1 압력 점검
- TP2 (압축기 토출 압력): 정상 범위 7.0 ~ 9.5 bar
- TP3 (패널 압력): 정상 범위 8.0 ~ 9.5 bar
- Reservoirs (저장조 압력): 7.5 bar 이상 유지
- 변동 폭이 ±0.5 bar 이상 지속되면 누설 의심

### 2.2 온도 점검
- Oil_temperature: 60 ~ 75°C 정상, 80°C 초과 시 즉시 부하 감소
- 주변 환기구 청결 여부 확인

### 2.3 전류 점검
- Motor_current 정상 부하 평균: 4.5 ~ 5.5 A
- 6.5 A 초과 지속 시 부하 원인 조사

## 3. 이상 발견 시 조치
1. 즉시 운전 일지 기록 (시간/현상/조치)
2. 안전한 경우 5분 모니터링 후 자가 회복 여부 확인
3. 회복되지 않으면 SOP-002 (Air Leak) 또는 SOP-003 (Oil) 절차 진입
4. 위험 신호 발생 시 비상 정지 (Pressure_switch HIGH, Oil_level LOW)

## 4. 점검 후 기록
- 점검 결과를 CMMS 시스템 입력
- 이상 발견 시 작업 지시서 자동 생성 트리거
