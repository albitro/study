## 핵심 요약

- 그래프는 정점(vertex)의 집합 V와 간선(edge)의 집합 E로 이루어진 자료구조 `G = (V, E)`다. 간선에 방향이 있으면 방향 그래프, 없으면 무방향 그래프다.
- 표현 방법은 두 가지: **인접 행렬**(2차원 배열, 공간 $O(n^2)$)과 **인접 리스트**(정점별 연결 리스트).
- 탐색은 **DFS**(스택, 갈 수 있는 데까지 파고듦, 전위순회 대응)와 **BFS**(큐, 가까운 곳부터, 레벨순회 대응) 두 가지가 핵심이다. 인접 리스트 기준 DFS의 시간 복잡도는 간선 수에 비례하는 $O(e)$다.
- DFS나 BFS를 정점마다 호출하면 서로 연결된 정점 묶음, 즉 연결 요소(connected component)를 찾을 수 있다.

## 1. 그래프의 개념

### 1.1 그래프의 응용

그래프는 "무언가와 무언가가 연결되어 있다"는 관계를 표현하는 데 쓰인다. 강의에서 든 활용 예는 다음과 같다.

- 회로망, 교통망, 지도
- 프로그램 흐름 분석
- 순서도(flowchart), 제어 흐름 그래프(control-flow graph)
- 상태 전이 다이어그램(state transition diagram)
- 활동 네트워크 다이어그램(AND): 프로젝트 관리 도구로 널리 쓰이며, 그룹/단계/작업 사이의 상호 의존 관계를 표시한다

한 번 그래프로 구성해 두면 최단 경로 찾기, 프로젝트 계획 같은 여러 작업에 그대로 활용할 수 있다.

### 1.2 오일러 문제: 쾨니히스베르크의 다리

1800년대 오일러가 제기한 문제로, **모든 다리를 딱 한 번씩만 건너서 처음 출발한 곳으로 돌아올 수 있는가**를 묻는다.

지역을 정점, 다리를 간선으로 바꾸면 이 문제를 그래프로 표현할 수 있다.

- 위치 -> 정점(node)
- 다리 -> 간선(edge)

**오일러 정리**로 이런 경로의 존재 여부를 판단할 수 있다.

- 모든 정점이 연결되어 있어야 한다.
- 차수가 홀수인 정점이 2개 이하여야 오일러 경로가 존재한다.

쾨니히스베르크 다리 문제는 차수가 홀수인 정점이 4개라서 오일러 경로가 존재하지 않는다.

### 1.3 그래프의 수학적 정의

그래프는 `G = (V, E)`로 쓰며,

- **V(G)**: 정점의 집합
- **E(G)**: 간선의 집합. 정점을 잇는 선으로, V × V의 부분집합이다.

간선의 방향 유무로 두 종류로 갈린다.


| 종류                       | 의미               | 비유             | 표기                             |
| ---------------------------- | -------------------- | ------------------ | ---------------------------------- |
| 무방향 그래프 (undirected) | 간선에 방향이 없음 | 양방향 통행 도로 | $(v_i, v_j) = (v_j, v_i)$        |
| 방향 그래프 (directed)     | 간선에 방향이 있음 | 일방통행 도로    | $⟨v_i, v_j⟩ \neq ⟨v_j, v_i⟩$ |

무방향 간선은 순서가 없어 `(vᵢ, vⱼ)`와 `(vⱼ, vᵢ)`가 같지만, 방향 간선은 순서가 있어 둘을 구별한다.

### 1.4 그래프의 예

강의에 나온 네 그래프의 수학적 표기.

- **G₁** (무방향, 정점 4개가 서로 다 연결)
  - V(G₁) = {0, 1, 2, 3}
  - E(G₁) = {(0,1), (0,2), (0,3), (1,2), (1,3), (2,3)}
- **G₂** (무방향, 트리 형태)
  - V(G₂) = {0, 1, 2, 3, 4, 5, 6}
  - E(G₂) = {(0,1), (0,2), (1,3), (1,4), (2,5), (2,6)}
- **G₃** (방향 그래프)
  - V(G₃) = {0, 1, 2}
  - E(G₃) = {⟨0,1⟩, ⟨1,0⟩, ⟨1,2⟩}
- **G₄** (연결된 부분이 둘로 나뉜 그래프)
  - V(G₄) = {0, 1, 2, 3, 4, 5, 6, 7}
  - E(G₄) = {(0,1), (0,2), (0,3), (1,2), (1,3), (2,3), (4,5), (5,6), (6,7)}

G₄는 {0,1,2,3} 묶음과 {4,5,6,7} 묶음이 서로 이어져 있지 않아, 연결된 부분이 두 개다.

### 1.5 그래프에서의 제한 사항

그래프에 어떤 조건을 걸었는지에 따라 종류가 나뉜다.


| 그래프                    | 제한 사항                                                         |
| --------------------------- | ------------------------------------------------------------------- |
| Simple Graph              | 두 정점 사이에 간선이 하나만 존재. 멀티 간선 없음, self-loop 없음 |
| Multigraph                | 두 정점 사이에 여러 간선을 허용                                   |
| Self-loop                 | 한 정점에서 자기 자신으로 가는 간선의 허용 여부                   |
| Directed vs. Undirected   | 간선이 방향성을 가지는지 여부                                     |
| Weighted vs. Unweighted   | 간선에 비용/거리/시간 같은 숫자 값이 붙는지 여부                  |
| Connected vs. Unconnected | 모든 정점이 간선으로 이어져 있는지 여부                           |

### 1.6 그래프 용어

**완전 그래프 (complete graph)**
간선 수가 최대인 그래프. 정점이 n개일 때 최대 간선 수는

- 무방향: n(n − 1) / 2
- 방향: n(n − 1)

정점이 3개면 무방향 최대 간선은 3개, 4개면 6개다.

**인접(adjacent)과 부속(incident)**
무방향 그래프에서 간선 (a, b)가 있을 때,

- 정점 a는 정점 b에 **인접**하다고 한다 (정점끼리의 관계).
- 간선 (a, b)는 정점 a와 b에 **부속**한다고 한다 (간선과 정점의 관계).

**부분 그래프 (subgraph)**
G의 부분 그래프 G′는 정점 집합과 간선 집합이 각각 원래 그래프의 부분집합인 그래프다.

- V(G′) ⊆ V(G)
- E(G′) ⊆ E(G)

**경로(path)와 그 길이**
정점 vₚ에서 vq로 가는 경로는, `(vₚ, v₁), (v₁, v₂), …, (vₙ, vq)` 같은 간선들이 차례로 존재할 때 성립한다. **경로의 길이**는 경로 위에 있는 간선의 수다.

- **단순 경로 (simple path)**: 처음과 마지막을 제외하고 정점이 모두 다른 경로. 즉 중간에 같은 정점을 다시 지나지 않는다.
- **사이클 (cycle)**: 처음과 마지막 정점이 같은 단순 경로. 출발점으로 다시 돌아오는 경우다. 방향 그래프에서는 방향성 사이클(directed cycle)이라 부른다.

**연결됨(connected)과 연결 요소**

- 정점 v₀와 v₁이 **연결**되었다는 것은 둘 사이를 잇는 경로가 있다는 뜻이다 (지도로 치면 통행로가 있음).
- **연결 요소 (connected component)**: 그래프의 모든 정점이 연결되어 있지 않을 수 있는데, 이때 최대로 연결된 부분 그래프 하나하나를 연결 요소라고 한다.

**트리**
사이클이 없고, 연결되어 있으며, 루트 노드가 하나 있는 그래프. 트리는 그래프의 한 종류다.

**강연결(strongly connected) - 방향 그래프**
방향 그래프에서 정점 쌍 vᵢ, vⱼ에 대해 vᵢ -> vⱼ 경로와 vⱼ -> vᵢ 경로가 **양쪽 다** 존재하면 두 정점은 강연결이다. 이런 성질을 만족하는 최대 부분 그래프가 **강연결 요소(strongly connected component)** 다.

**차수(degree of vertex)**
정점에 부속된 간선의 수. 방향 그래프에서는 둘로 나뉜다.

- **in-degree**: 정점으로 들어오는 간선의 수
- **out-degree**: 정점에서 나가는 간선의 수

**가중치 간선 (weighted edge)**
간선에 붙는 숫자 값. 정점에서 정점으로 가는 거리나, 도달하는 데 드는 비용을 뜻한다.

## 2. 그래프의 표현

### 2.1 인접 행렬

정점 수가 n인 그래프를 n x n 크기의 2차원 행렬에 저장하는 방법이다.

```
adj_mat[i][j] = 1  (vᵢ, vⱼ)가 인접할 때
              = 0  인접하지 않을 때
```

- 필요한 기억장소 크기(공간 복잡도)는 $S(n) = n^2$이다.
- 무방향 그래프의 인접 행렬은 대각선을 중심으로 대칭(symmetric)이다. `adj_mat[i][j] == adj_mat[j][i]`이기 때문이다.

예를 들어 G₁의 인접 행렬은 다음과 같다.

```
    0 1 2 3
  0 0 1 1 1
  1 1 0 1 1
  2 1 1 0 1
  3 1 1 1 0
```

### 2.2 인접 리스트

정점 수만큼(n개)의 연결 리스트로 그래프를 표현한다. 각 정점마다 그 정점과 연결된 간선(즉 인접 정점)을 하나의 연결 리스트에 담고, 이 리스트들을 배열로 묶는다.

```
#define MAX_VERTICES 50
struct list_node {
    int vertex;
    struct list_node * link;
};
typedef struct list_node node;
typedef node * node_ptr;
node_ptr graph[MAX_VERTEX];
```

각 노드는 `vertex`(인접 정점 번호)와 `link`(다음 노드로 가는 포인터) 두 칸으로 이루어진다.

## 3. 그래프의 탐색

### 3.1 그래프의 추상 데이터 타입

- **객체**: 정점의 집합과 간선의 집합
- **연산**:


| 연산                   | 의미                                       |
| ------------------------ | -------------------------------------------- |
| `create_graph()`       | 그래프를 생성한다                          |
| `init(g)`              | 그래프 g를 초기화한다                      |
| `insert_vertex(g, v)`  | 그래프 g에 정점 v를 삽입한다               |
| `insert_edge(g, u, v)` | 그래프 g에 간선 (u, v)를 삽입한다          |
| `delete_vertex(g, v)`  | 그래프 g의 정점 v를 삭제한다               |
| `delete_edge(g, u, v)` | 그래프 g의 간선 (u, v)를 삭제한다          |
| `is_empty(g)`          | 그래프 g가 비어 있는지 확인한다            |
| `adjacent(v)`          | 정점 v에 인접한 정점들의 리스트를 반환한다 |
| `destroy_graph(g)`     | 그래프 g를 제거한다                        |

### 3.2 탐색이란

그래프의 각 정점을 방문하는 것을 **탐색(traversal)** 이라 하며, 그래프 연산 중 가장 중요하다. 방문 순서에 따라 두 방법이 있다.

- **DFS (깊이 우선 탐색)**: 갈 수 있는 데까지 파고드는 방식. 트리의 전위순회(preorder)를 그래프에 적용한 것.
- **BFS (너비 우선 탐색)**: 가까운 곳부터 훑는 방식. 트리의 레벨순회(level order)를 그래프에 적용한 것.

### 3.3 깊이 우선 탐색 (DFS)

**아이디어.** 자동차로 여행할 때, 갈 수 있는 곳이 보이면 일단 계속 앞으로 간다. 되돌아오는 건 길이 막혔거나 이미 가 본 곳일 때뿐이다. 되돌아온 뒤에는, 마지막으로 갈림길이 있었던 지점 중 아직 안 가 본 길로 다시 나아간다.

방문할 수 있는 곳은 **스택**에 저장한다. 동작 단계는 다음과 같다.

1. 시작 노드 하나를 고른다.
2. 노드를 방문해 할 일을 하고, 연결된 다음 노드를 찾는다. 현재 노드는 스택에 넣는다. 이 단계를 반복하다가 더 갈 곳이 막히면 3단계로 간다.
3. 방문할 노드가 없으면 스택에서 노드를 꺼내 그다음 갈 곳을 찾고 2단계로 돌아간다.

방문 여부는 `visited[MAX_VERTICES]` 배열로 표시한다. 처음엔 모두 FALSE, 방문하면 TRUE로 바꾼다. 갈 수 있는 곳이 여럿이면 노드 번호가 작은 쪽을 먼저 방문한다.

```
/* 정점 v에서 시작하여 그래프의 깊이 우선 방문 */
void dfs(int v) {
    node_ptr w;
    visited[v] = TRUE;          /* 1. 방문 표시 */
    printf("%5d", v);
    for(w = graph[v]; w; w = w->link)   /* 2. 인접 리스트 탐색 */
        if(!visited[w->vertex])
            dfs(w->vertex);
}
```

인접 리스트로 표현했을 때 DFS의 **시간 복잡도는 $O(e)$** (e는 간선의 수)다.

### 3.4 너비 우선 탐색 (BFS)

**아이디어.** 자동차 여행에서 가까운 곳부터 방문하는 방식이다. 어느 지점에서 갈 수 있는 가까운 곳을 방문하고, 그다음 갈 수 있는 지점들은 모두 저장해 둔다. 다음 방문지는 항상 저장해 둔 곳에서 넣은 순서대로 꺼낸다. 먼저 저장된 곳을 먼저 방문하므로 **큐**를 사용한다.

동작 단계:

1. 시작 노드 하나를 고른다.
2. 노드를 방문해 할 일을 하고, 연결된 다음 노드들을 모두 큐에 저장한다. 더 넣을 게 없으면 3단계로 간다.
3. 큐의 맨 앞 노드를 꺼내 2단계를 반복한다.

DFS와 마찬가지로 `visited[MAX_VERTICES]` 배열로 방문을 표시한다.

```
/* 정점 v에서 시작하여 그래프의 너비 우선 방문 */
void bfs(int v) {
    node_ptr w; queue_ptr front, rear;
    front = rear = NULL;        /* 큐 초기화 */
    printf("%5d", v);
    visited[v] = TRUE;          /* 1. 방문 기록 */
    insert(&front, &rear, v);
    while(front) {              /* 2. 방문지가 있는 동안 반복 */
        v = delete(&front);
        for(w = graph[v]; w; w = w->link)
            if(!visited[w->vertex]) {
                printf("%5d", w->vertex);
                insert(&front, &rear, w->vertex);
                visited[w->vertex] = TRUE;
            }
    }
}
```

### 3.5 연결 요소 계산

DFS나 BFS는 **경로가 이어진 노드들만** 방문한다. 이 성질을 이용해, 모든 정점을 돌면서 아직 방문 안 한 정점에서 DFS를 새로 호출하면 연결 요소를 하나씩 찾을 수 있다.

```
void connected(void) {
    int i;
    for(i = 0; i < n; i++) {
        if(!visited[i]) {
            dfs(i);
            printf("\n");
        }
    }
}
```

G₄에 이 알고리즘을 적용하면 출력이 두 줄로 나뉜다. 즉 연결 요소가 2개다.

```
0 1 2 3
4 5 6 7
```

### 문제 2. dfs(0), bfs(0) 스패닝 트리 구하기

그래프 간선: 0–1, 0–2, 1–2, 2–3, 2–5, 3–4, 3–6, 5–7. (갈림길에서는 번호가 작은 쪽 먼저)

**DFS(0)** - 스택으로 깊이 우선. 방문 순서와 트리 간선:

```
방문 순서: 0 -> 1 -> 2 -> 3 -> 4 -> 6 -> 5 -> 7
트리 간선: (0,1) (1,2) (2,3) (3,4) (3,6) (2,5) (5,7)
```

- 0에서 1로, 1에서 2로 내려간다.
- 2의 이웃 3으로 가서 3의 이웃 4를 방문(4는 막힘 -> 되돌아옴), 이어 6을 방문(막힘 -> 되돌아옴).
- 2로 돌아와 5로 가고, 5에서 7을 방문하며 끝난다.

**BFS(0)** - 큐로 너비 우선. 방문 순서와 트리 간선:

```
방문 순서: 0 -> 1 -> 2 -> 3 -> 5 -> 4 -> 6 -> 7
트리 간선: (0,1) (0,2) (2,3) (2,5) (3,4) (3,6) (5,7)
```

- 0의 이웃 1, 2를 큐에 넣는다.
- 1을 꺼내면 새 이웃 없음(2는 이미 방문 예정). 2를 꺼내 이웃 3, 5를 넣는다.
- 3을 꺼내 이웃 4, 6을 넣고, 5를 꺼내 이웃 7을 넣는다. 나머지를 순서대로 비우면 끝.

> 두 트리 모두 정점 8개에 간선 7개(= n − 1)로, 사이클 없이 전체를 연결한다.

### 문제 3. 인접 행렬로 주어진 그래프의 DFS·BFS

10 × 10 인접 행렬(정점 0~9). 행별로 1인 위치(이웃)를 정리하면:

```
0 -> 1, 2, 4, 6
1 -> 0
2 -> 0, 3, 8
3 -> 2, 5, 7
4 -> 0
5 -> 3, 9
6 -> 0, 7
7 -> 3, 6
8 -> 2
9 -> 5
```

**DFS(0)** (번호 작은 이웃 먼저):

```
0 -> 1 -> 2 -> 3 -> 5 -> 9 -> 7 -> 6 -> 8 -> 4
```

- 0->1(막힘, 복귀) -> 0->2->3->5->9(막힘, 복귀) -> 5 복귀 -> 3->7->6(6의 이웃 0·7 모두 방문됨, 복귀) -> 7 복귀 -> 3 복귀 -> 2->8(막힘, 복귀) -> 0->4로 끝.
- 이는 강의 코드의 실행 결과 `0 1 2 3 5 9 7 6 8 4`와 일치한다.

**BFS(0)**:

```
0 -> 1 -> 2 -> 4 -> 6 -> 3 -> 8 -> 7 -> 5 -> 9
```

- 0의 이웃 1,2,4,6을 넣는다.
- 1(새 이웃 없음) -> 2(3,8 추가) -> 4(없음) -> 6(7 추가) -> 3(5 추가; 7은 이미 큐) -> 8(없음) -> 7(없음) -> 5(9 추가) -> 9.
- 이는 강의 코드의 실행 결과 `0 1 2 4 6 3 8 7 5 9`와 일치한다.
